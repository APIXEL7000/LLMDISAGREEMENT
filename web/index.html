Do AI models agree with each other?

Ask two or more AIs the same questions and see where their answers differ. Works with OpenAI, Gemini, Claude and local Ollama models.

2

Choose the AIs to compare

Add two or more, up to eight. Three gives a clear majority, so you can see which one is the odd one out. You can use several Ollama models at once: add each one as its own row. Rows without a model name are ignored.

How to set up Gemini or Ollama
Gemini
  1. Get a free key at aistudio.google.com/app/apikey.
  2. Add GEMINI_API_KEY=your-key to the .env file next to main.py and restart the server.
  3. Add a row with provider Google Gemini and the model name from AI Studio, then click Test.
Ollama (free, runs on your computer)
  1. Install it from ollama.com/download and make sure it is running.
  2. Download models in a terminal, e.g. ollama pull <model name>. Run ollama list to see what is installed.
  3. Click Find my Ollama models and click each model you want to compare. Each click adds a row.

Keys are best kept in .env. A key typed on this page is used for this run only and is never saved.
